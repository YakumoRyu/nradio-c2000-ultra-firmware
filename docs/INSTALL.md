# 安装

## 完整固件

适用设备为板型标识`NRadio-C2000MAX-Ultra`的Ultra，启动于本项目适配的TF系统。完整固件使用**sysupgrade**格式，通过当前TF系统的“系统→备份/升级”入口安装。

布局兼容号为**2.0**，根分区内预留**512MiB**。TF整卡初始化和内置官方系统使用各自的安装介质与流程。

1. 核对板型、TF启动状态与布局兼容号。
2. 备份个人配置、应用数据和短信库，准备官方系统恢复入口。
3. 查看对应Release的验证记录。r6当前为整镜像待实机启动验收的预发布版。
4. 在TF系统的系统升级页上传sysupgrade，并完成板型与布局检查。
5. 启动后检查5G、Wi-Fi、IPv4/IPv6、UPnP与各项服务，再恢复个人应用数据。

## 维护升级包

本次[累计维护升级包](../releases/ultra-maintenance-20261016-2/README.md)用于已安装r4或r5更新的Ultra25.12系统，包含CPU与运营商图标修复。安装前校验源文件并自动备份，正常重启保留。

现有Ultra25.12 TF系统可使用[维护升级包](../releases/ultra-maintenance-20261015-1/README.md)。把归档上传到`/tmp`，解压后执行其中的`install.sh`。安装器核对源文件、保存备份并应用网口与显示补丁，保留配置。

网口设置入口为**网络→网口切换**，首页网口1卡片也有按钮。应用后90秒内点击“保留更改”；到期自动恢复原配置。

## 离线软件仓库

使用与固件标签相同的可选软件仓库。解压到`/overlay/ultra-packages/`，使该目录直接包含`RELEASE`和各软件源目录，然后执行：

```sh
/usr/sbin/ultra-package-feeds
opkg update
```

内置程序可直接使用，仓库用于安装与当前版本匹配的其他软件包。

## 恢复出厂

完整固件中的通用程序与补丁保留，个人密码、订阅和短信/媒体数据按系统恢复流程清理。恢复后重新设置网络与服务。独立安装到可写区的维护升级包随可写区重置，ROM中的r6补丁长期保留。
