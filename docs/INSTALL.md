# 安装与兼容性

## 适用范围

仅适用于板型标识为 `NRadio-C2000MAX-Ultra` 的 Ultra 设备。当前文件为 **sysupgrade**，不是完整 TF 卡 IMG。不得将它作为整卡镜像写入，也不要提交到内置官方系统的普通固件升级入口。

本版布局兼容号为 **2.0**，根分区内只读固件预留 **512 MiB**。旧 TF 系统可能使用其他数据区偏移；旧布局迁移需要单独处理，不能强制忽略兼容性检查。

## 升级前确认

1. 核对设备型号、当前启动介质和布局兼容性。
2. 自行备份个人配置、应用数据和短信库，确认内置官方系统的恢复方式可用。
3. 查看对应 Release 的验证状态。r2 当前仍是整镜像待实机启动验收的预发布版。
4. 在兼容的现有 TF 系统中使用其系统升级入口，并保留系统的型号和兼容性检查；不要使用强制升级选项。

本项目不提供不分型号或布局的“一键强刷”命令。

## 离线软件仓库

只在运行同一版本固件时使用配套归档。将归档解压到 `/overlay/ultra-packages/`，确保该目录直接包含 `RELEASE` 和各软件源子目录，然后运行：

```sh
/usr/sbin/ultra-package-feeds
opkg update
```

已内置的程序不依赖先安装此仓库。不要混用其他 snapshot 的内核模块或其他版本仓库。

## 恢复出厂

通用补丁与内置程序留在只读系统中；个人密码、订阅、短信/媒体数据和可选仓库属于可写数据，应提前备份。恢复后需要重新配置服务。公开镜像不会自动恢复维护者的账号或私人服务。
