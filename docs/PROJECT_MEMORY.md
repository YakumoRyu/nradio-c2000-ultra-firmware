# 项目记忆

## 设备与基线

- 维护设备：NRadio C2000Ultra，板型`NRadio-C2000MAX-Ultra`，四核，TF系统。
- 基线：ImmortalWrt25.12、Linux6.12.103、联发科闭源Wi-Fi8.3.1.2、巴龙WebUI3.0.2-r2。
- `eth0`为网口1，可切换WAN/LAN；`eth1`为网口2 LAN；`eth2`为5G。
- 默认LAN为192.168.66.1，网口1、2均属LAN。个人设备规则留在配置中。
- AT仅由QModem的`ubus-at-daemon`持有；WebUI和短信通过共享服务操作。

## 2026-10-15适配

1144原版网口功能面向单口MAX，Ultra采用独立`ultra-port-manager`实现。提供DHCP、PPPoE、静态IPv4和接入提示；配置提交后90秒内确认，未确认自动回退。

网口弹窗采用居中白色圆角卡片、模糊背景、渐变图标、信息行与紫色按钮。修复模组型号/IMEI被`^PDCPDATAINFO`主动上报污染，以及侧栏型号断字。

维护升级包与完整固件分别发布，通用修复进入完整固件ROM。共享固件采用通用出厂数据，个人配置、账号和业务数据单独保存。

## 长期约定

- 每次修复完成验收后，自动制作并上传保留配置的升级包和集成修复的完整固件，分别发布到GitHub，不需要用户再次提醒。同步源码、安装/回退说明、验证记录，并核对CI及公开下载；在线修复或只推源码不能作为本项目的修复交付终点。
- 保留原登录页、闭源Wi-Fi、5G、UPnP/IPv6、PCDN绕过、短信和媒体功能。
- 生产改动先读取现状、备份，再实施可回退的小改动，最后以真实行为验收。
- 安装网口功能时保持现有角色，用户在界面选择切换。
- UI、README和发布说明用直接、简洁的事实与步骤；省去防御性、免责式和反复自我限定的措辞。
- 验证记录直接写完成项与待验收项；升级包实机安装和完整镜像启动分别记录。
- 文档与公开产物不包含个人凭据、订阅、短信或媒体数据。

## 2026-10-16 CPU与首页修复

5G分钟自愈检查改为候选进程筛选，首页CPU采用共享非阻塞采样与原生状态读取；普通LAN布局不查询已移除的PCDN独立接口。源码提交66b4538的5个修复文件进入完整r5 ROM，同时提供独立可回退升级包。公开包仅包含通用代码与配置。

单次自愈检查CPU从0.748秒降至0.073秒；这是单次检查的CPU时间，不代表整机降幅。持续几分钟的卡顿需要现场采样，与已复现的短时开销分别跟踪。

## 2026-10-16 运营商图标与自动双包发布

修复提交ac90f2e补齐移动、电信、广电图标，并增加加载完成显示、失败隐藏和按来源变更加载。累计维护升级包支持r4/r5，完整r6将同一修复编入ROM。此后每次修复都完成升级包和完整固件的GitHub发布、校验与下载验收，无需用户再次提醒。

## 2026-10-17 无线RX DMA恢复

故障窗口捕获零DMA地址、token/地址错配及EMI越界记录，随后电脑断线并触发网卡恢复。补丁954在异常RX描述符路径通过厂商SER level10.0异步请求恢复，30秒节流；补充DMA所有权后的读屏障，先校验再分配，ENOMEM不触发恢复。原有952 NAPI补丁保留。实机重启已加载同一驱动，双频、5G双栈与用户网页/后台复验通过。对应累计升级包为ultra-maintenance-20261017-1，完整预发布为ultra-25.12-20261017-r7；整镜像尚未刷写。不要通过热解绑mt7992部署驱动。
