## 2026-11-04 手机LuCI首页卡顿

现场抓到I/O等待约60%、大量进程阻塞在文件页读取，Mihomo一分钟发生15万余次主缺页；早上内核也记录了Wi-Fi MLME连续页申请失败。Emby在压缩交换中持有大量冷页；暂停它后可用内存恢复到约310MiB、交换占用明显下降，之后由资源保护程序自动恢复。未重启路由器或代理核心，保留后台追赶分析。

首页网关接口原来每两秒重复ping当前/蜂窝同一接口，蜂窝请求最长7秒而页面每4秒再次发起。修复为按类型单个在途、适度刷新，并通过非阻塞文件锁缓存跨页面合并网关/蜂窝采集；过期、失败和时钟回退有界处理。首页原样式与登录页面保持。

资源保护对暂停超时保留所有权是必要的，但长期stopping时所有权过滤会阻止压力下再次请求暂停。增加每服务至少120秒间隔、每小时最多3次的重试预算并持久化；文件程序页重读导致的低内存高I/O也可触发，不再要求交换读入同时达到门限。原有停止确认、逐个恢复和资源门限继续有效。

内存水位调整的现场试验没有改善卡顿，已撤回且未进入最终补丁或ROM；保持原min_free_kbytes、watermark参数与zram配置。手机用户确认恢复正常。发布独立ultra-maintenance-20261104-1与完整预发布ultra-25.12-20261104-r15，完整镜像未刷入生产设备。个人参数只保留在线配置，公开固件不打包现场备份。

持续监测期间Emby自动恢复后再次出现资源挤占，新保护程序成功再次暂停Emby，随后路由响应恢复。最终运行验收以现场保护状态为准，Emby暂时暂停需在交付中明确，不能把手机后台恢复等同于所有媒体服务持续运行。
