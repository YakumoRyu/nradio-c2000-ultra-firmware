# Ultra25.12 r11完整固件

将WebUI扫频准备、异步应答过滤、ARFCN解析和异常恢复编入ROM，恢复出厂后仍保留这些修复。原登录页面、媒体保护、短信共享存储及此前网络修复继续集成。

| 项目 | 版本 |
| --- | --- |
| 系统 | ImmortalWrt25.12-SNAPSHOT |
| 内核 | Linux6.12.103 |
| 无线 | 联发科闭源8.3.1.2 |
| 巴龙WebUI | 3.0.2-r3 |
| 格式 | Ultra专用sysupgrade |

下载`ultra-25.12-20261026-r11-nradio-c2000ultra-sysupgrade.bin`；配套离线软件仓库为`ultra-25.12-20261026-r11-optional-packages.tar.gz`。安装步骤见[固件安装说明](../../docs/INSTALL.md)。

与r10相比，内核和无线驱动字节相同，本次更新WebUI二进制及页面、软件包元数据和版本标识。公开镜像采用通用出厂配置，个人小区锁定、账号、短信和媒体数据均不写入镜像。

本版为预发布：同一WebUI二进制已在实机完成定向扫描、原设置恢复、双栈访问及10分钟稳定性验证；完整镜像通过结构、包ABI、源码差异、隐私和19项用户态运行检查，整镜像启动及恢复出厂尚未实机执行。

已有r10用户可使用单独的[WebUI升级包](../ultra-maintenance-20261026-1/README.md)，无需刷写完整固件。
