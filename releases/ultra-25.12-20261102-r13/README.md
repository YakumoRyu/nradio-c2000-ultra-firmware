# Ultra25.12 r13完整固件

将邻区信号优先策略及PCDN设备转发白名单编入ROM，保留原内核6.12.103、联发科闭源无线8.3.1.2、巴龙WebUI3.0.2-r3、OpenClash0.48.002和Mihomo1.19.33。

完整镜像：`ultra-25.12-20261102-r13-nradio-c2000ultra-sysupgrade.bin`。配套软件仓库：`ultra-25.12-20261102-r13-optional-packages.tar.gz`。

原登录页及既有修复保持，网口1/2默认LAN，出厂配置不包含个人数据。新策略支持首选频点并在启用时校验设置；出厂默认关闭，可按升级包说明启用；不自动离网扫频。安装步骤见[完整固件安装](../../docs/INSTALL.md)。

PCDN白名单按设备MAC和LAN接口匹配，IPv4/IPv6出站先于OpenClash全局过滤放行，IPv6入站跟随当前公网地址，保留IPv4的NAT与UPnP。公共出厂配置默认关闭，个人设备清单通过现有配置恢复。

镜像内容、隐私和用户态检查通过后发布为预发布；整镜像未在生产设备刷写。当前在线设备使用相同的策略与白名单代码。仅安装本次修复可用[独立升级包](../ultra-maintenance-20261102-1/README.md)。
