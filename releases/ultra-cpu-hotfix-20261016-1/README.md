# Ultra CPU与首页修复升级包 — 2026-10-16

适用于已安装本项目r4网口与显示更新的Ultra25.12 TF系统。安装保留个人配置，正常重启后继续生效。

## 修复内容

- 每分钟5G自愈检查先筛选候选进程，减少进程创建。实测单次检查CPU时间从0.748秒降至0.073秒，系统新增进程从443个降至29个。
- 首页CPU使用共享非阻塞采样，取消请求内的1秒等待，并分开计算CPU忙碌与I/O等待。
- 首页设备信息复用原生ubus、UCI和proc读取；预热状态接口平均耗时从1.184秒降至0.117秒。
- 页面隐藏时暂停设备状态轮询。
- 独立PCDN接口已移除时停止查询旧接口，修复空响应引起的JSON解析错误。

## 安装与回退

将`ultra-cpu-hotfix-20261016-1-upgrade.tar.gz`上传至路由器`/tmp`，执行：

```sh
tar -xzf /tmp/ultra-cpu-hotfix-20261016-1-upgrade.tar.gz -C /tmp
sh /tmp/ultra-cpu-hotfix-20261016-1/install.sh
```

安装器核对5个文件的原始与目标校验值，备份至`/overlay/ultra-hotfix-backups/cpu-20261016-r1/`。已安装相同修复时直接返回；安装后刷新管理页。

需要回退本包实际安装的文件时执行：

```sh
python3 /tmp/ultra-cpu-hotfix-20261016-1/ultra-cpu-hotfix.py rollback
```

原文件已被其他更新修改时，安装器会列出需核对的路径。恢复出厂后的ROM修复由[完整r5固件](../ultra-25.12-20261016-r5/README.md)提供。

## 验证

修复已在运行中的Ultra安装，5G、IPv4/IPv6、OpenClash、UPnP和媒体API检查通过。修复后的5分钟样本CPU平均13.63%、峰值50%，没有采集到整机80%以上的样本；该窗口用于记录运行状态。
