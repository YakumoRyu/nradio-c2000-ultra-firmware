# LuCI首页与媒体资源保护升级包

减少手机访问LuCI首页时的重复状态采集：设备信息5秒、网关10秒、蜂窝信息5秒刷新；同类请求最多一个在途。多个页面共用非阻塞缓存，过期缓存仅在限定时间内使用。网关同一接口只探测一次，未连接网口跳过探测。

修正媒体暂停请求超时后一直停留在“正在停止”的问题。压力持续时允许间隔至少120秒、每服务每小时最多3次暂停请求；保留停止确认、分阶段恢复和原来的资源限制。低内存伴随持续文件页读写等待也进入保护，不要求压缩交换读入量同时达到门限。Emby后台分析设置保持。

包名：`ultra-maintenance-20261104-1.tar.gz`。更新6个文件，重启媒体保护程序加载新逻辑，无需整机重启。

```sh
tar -xzf ultra-maintenance-20261104-1.tar.gz
cd ultra-maintenance-20261104-1
python3 install.py apply
```

安装保留个人网络、代理、PCDN、短信和媒体数据。回退在原解压目录执行`python3 install.py rollback`。查看资源保护状态：`cat /tmp/codex-media-protection.json`。本包不修改内存水位、压缩算法或交换配置。

验证覆盖并发请求合并、过期/错误缓存、网关探测去重、暂停重试和安装回退；移动版页面及实际运行结果见VERIFICATION.json。完整固件见[完整r15](../ultra-25.12-20261104-r15/README.md)。
