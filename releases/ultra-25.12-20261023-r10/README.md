# Ultra25.12 r10完整固件

版本：`ultra-25.12-20261023-r10`。

ImmortalWrt25.12-SNAPSHOT、Linux6.12.103、联发科闭源Wi-Fi8.3.1.2、巴龙WebUI3.0.2-r2。

r10修复媒体保护程序把尚未退出的容器误判成已恢复，导致Emby延迟退出后未能重启的问题。系统分别保存等待停止、已停止、正在启动阶段；跨进程重启保留恢复目标，Docker接口超时不会提前清理目标。

下载：

- `ultra-25.12-20261023-r10-nradio-c2000ultra-sysupgrade.bin`：完整固件，约206MiB。
- `ultra-25.12-20261023-r10-optional-packages.tar.gz`：配套690个软件包及索引签名。
- `VERIFICATION.json`：构建、镜像、运行与公开产物检查结果。

与r9相比只更新媒体保护程序和两个版本/仓库标识文件。内核、无线驱动、原登录页、5G、UPnP/IPv6、短信与网口管理保持现有基线。镜像采用通用出厂配置，不含个人服务数据。

在线补丁已完成自动恢复验证、21项媒体保护测试和15分钟可用性监测。Emby、MediaWarp和OpenList运行正常，AutoFilm后台导入仍等待224MiB内存恢复门槛。完整镜像已解包检查、核对差异并完成用户态检查，整镜像启动及恢复出厂待实机验收，本Release保持预发布。

安装步骤见[完整固件安装](../../docs/INSTALL.md)。已安装系统可使用[保留配置升级包](../ultra-maintenance-20261023-3/README.md)。
