# Ultra 25.12 — 20261009-r2

适用设备：NRadio-C2000MAX-Ultra。基线保持ImmortalWrt25.12-SNAPSHOT、Linux6.12.103及联发科闭源Wi-Fi驱动。

此版本将巴龙WebUI更新为上游发布标签v3.0.2，并集成QModem兼容补丁，包版本为3.0.2-r2。取消的Vantage主题没有安装；原Argon登录页面字节保持一致。

短信管理与转发共同使用QModem持久短信库。Web查看不修改已读状态，不领取转发任务；删除采用独立数据库编号，避免误删SIM槽位。Go后端通过现有AT服务发指令，QModem仍是唯一串口持有者。PushPlus通用转发脚本和custom_script入口已进入ROM；出厂不包含个人Token或转发目标。

此前固化的驱动空转、设备流量计数、UPnP、5G拨号和媒体资源保护修复均保留。工厂默认不启用个人媒体服务或PCDN设备规则，需要用户自行配置。镜像未包含个人密码、SSH密钥、订阅、域名、短信数据库、媒体数据或设备校准。

主文件是sysupgrade固件，约205.93MiB，适用于已有Ultra适配TF系统及布局兼容版本2.0；不是完整TF卡IMG，不能直接作为整卡烧录文件，也不能用于内置官方系统的普通升级入口。

可选软件包仓库约144.03MiB，与此镜像匹配，单独交付，未嵌入主固件。仅在启动本版固件后，将仓库解压到`/overlay/ultra-packages`，再运行`ultra-package-feeds`刷新软件源。本版仓库标识为ultra-25.12-20261009-r2，旧版仓库不可混用。

已完成镜像解包、板型/内核ABI/驱动/布局/原登录页/隐私检查，以及18项用户态执行检查。3.0.2适配版已安装到当前路由器，网络、系统、短信和拨号页面经真实浏览器验收；短信库与转发任务保持一致。只有Web服务重启，整机未重启。

此次新镜像尚未刷写，尚未完成整镜像实机启动或真实恢复出厂测试。新短信到达时同时查看Web与接收PushPlus的端到端测试仍待实际短信。短信发送/删除、扫频和改锁频未在生产SIM上执行。B025有两条非必需查询不支持：AT^TXPOWER?和AT^CASCELLINFO?，不会阻止这些已验收页面加载。
