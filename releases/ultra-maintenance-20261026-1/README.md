# Ultra扫频与锁区恢复升级包

修复锁定频点或小区后全网扫频返回`CME ERROR: 3`的问题。扫描前保存原NR/LTE锁定及拨号设置，临时解除锁定并等待无线连接空闲；扫描结束、取消或异常退出后恢复。扫描会短暂中断5G数据，Wi-Fi保持连接。

本包用于本项目25.12、Linux6.12.103，且WebUI为3.0.2-r2的Ultra设备，包括完整r10。它单独更新WebUI，不替代以前的累计维护包；较早固件请先完成对应维护升级。已安装同一r3版本时重复执行不改动文件。

## 安装

将附件`ultra-maintenance-20261026-1.tar.gz`上传到路由器的`/tmp`，执行：

```sh
cd /tmp
tar -xzf ultra-maintenance-20261026-1.tar.gz
python3 ultra-maintenance-20261026-1/install.py apply
```

安装器校验包和现有文件，使用opkg安装3.0.2-r3，保留配置，仅重启WebUI服务。出现安装错误时回退原包。备份保存在`/overlay/ultra-hotfix-backups/webui-20261026-r1`。

手动回退：

```sh
python3 /tmp/ultra-maintenance-20261026-1/install.py rollback
```
